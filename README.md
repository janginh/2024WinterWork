목적
도메인 모니터링 17,000여건을 확인하기 위해 파이썬으로 프로그램 제작

엑셀에 존재하는 웹사이트를 확인하여 Chrome에서 F12 DevTools를 기반으로 단어 검색


1. 접속불가한 도메인 찾기
2. 사이트 속 "교회"라는 단어를 찾기
3. 1번 2번을 결합
    - 만들던 도중 프로그램이 데이터량을 많이 잡아 먹는다는 사실을 발견
       => 접속 가능한 경우만 driver을 이용하여 단어를 찾도록 실행

* 당시 외부망을 사용하기 위해 egg를 사용하여 데이터 사용량 또한 감안하여 방어적으로 프로그램 작
